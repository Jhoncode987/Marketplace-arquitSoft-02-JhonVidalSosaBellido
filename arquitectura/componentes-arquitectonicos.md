# Componentes Arquitectónicos del Sistema

## Descripción General de Componentes

El **Marketplace de Productos para Mascotas (GoPet)** está diseñado como un **Monolito Modular organizado en capas**, donde cada módulo interno representa un componente delimitado del dominio del negocio.
